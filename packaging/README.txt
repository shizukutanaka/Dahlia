Dahlia - Windows ポータブル版 (V0.3) クリーン全部入り版
====================================

ローカルで人物 Identity を管理する AI クリエイター向けアプリです。
インストール不要・レジストリ不使用。このフォルダごと好きな場所に
置いて使えます。削除するときはフォルダごと消すだけです。

■ 起動方法
  Dahlia.bat をダブルクリックしてください。窓がタスクバーに
  出ることがあるので、見当たらないときはタスクバーと
  Alt+Tab を確認してください。
  初回起動時に自己診断 (selfcheck.txt) が自動で作られます。

■ 必要なもの
  - Windows 10 / 11 (64bit)
  - WebView2 ランタイム (Windows 11 と最近の Windows 10 には
    標準で入っています。Edge が動く環境なら通常そのまま使えます)
  - 空き容量: このフォルダで約 160MB、データ保存分は別途少量

■ データの保存先
  プロジェクトや顔データは Windows のアプリデータ領域
  (com.dahlia.studio) に保存されます。このフォルダ内ではありません。

■ 機能の範囲 (このパッケージ)
  - 写真の読み込み、顔検出、人物の自動分類、一覧・詳細: 使用可
  - 3D 空間ビュー (Identity の 3D 配置): 使用可
  - AI 深度レリーフ: models フォルダに depth-anything-v2-small.onnx
    を置くと有効になります (任意)
  - 3D 顔プレビュー: この全部入り版には導入済みです

■ うまく動かないとき
  selfcheck.txt の内容を確認してください。
  numpy / PIL / onnxruntime がすべて OK になっていれば
  Python 側は正常です。結果を Muse に伝えると原因が切り分けられます。
